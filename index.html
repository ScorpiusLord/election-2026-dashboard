      Methodology

      • Vote counts come only from sourced records (state election-office feeds or a CSV with a source URL and timestamp). Nothing is estimated.
      • A race is called only when the data carries an explicit called=true flag with a source. State results feeds never call races; vote leads are not calls.
      • House/Senate bars count called seats only. Senate hatched segments are the 65 seats not on the 2026 ballot.
      • All times shown in Central Time (America/Chicago).

      Live data feed

      Poll an HTTPS URL that returns JSON (an array of records, or {"results":[…]}) or CSV with columns race_id,candidate,party,votes,called,source,updated_at. The server must allow CORS. Records without a valid HTTPS source and ISO timestamp are rejected. When this page is served over http(s) next to results.json, it also re-reads that file automatically every 60 s.
